# Pusapati Raghavendra - Portfolio Website

A modern, responsive, and eye-catching portfolio website showcasing my skills, experience, and projects.

## Features

- **Fully Responsive Design** - Works seamlessly on all devices (desktop, tablet, mobile)
- **Modern UI/UX** - Clean design with smooth animations and gradients
- **Sections Include:**
  - Hero section with profile image
  - About Me with education details
  - Work Experience timeline
  - Featured Projects with live demo links
  - Technical Skills showcase
  - Certifications
  - Contact information

## Technologies Used

- HTML5
- CSS3 (with CSS Variables and Flexbox/Grid)
- Vanilla JavaScript
- Font Awesome Icons

## Setup Instructions

1. Save your profile photo as `photo.jpg` in the same directory as the HTML file
2. Open `index.html` in your web browser
3. That's it! No build process required.

## Customization

- **Colors:** Edit CSS variables in `styles.css` under `:root`
- **Content:** Modify the HTML content in `index.html`
- **Animations:** Adjust timing and effects in `script.js`

## Project Structure

```
portfolio/
│
├── index.html          # Main HTML file
├── styles.css          # All styles and responsive design
├── script.js           # Interactive features
├── photo.jpg           # Your profile photo
└── README.md          # This file
```
